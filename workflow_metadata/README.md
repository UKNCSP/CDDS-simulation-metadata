## Workflow metadata files

The workflow metadata files in this folder are created when the `Add/Modify Workflow Metadata` issue form is submitted. Each file is named using the unique model workflow ID provided in the submission (for example, `u-dv341`).

> **NOTE:**
>  Do not edit any workflow metadata files directly within the repository. If you need to update information within a file or remove a configuration file, please open an issue and include the relevant model workflow ID, along with a clear description of the requested change.

Any updates to workflow metadata files must be carried out by a member of the CDDS team. This ensures that all changes are properly documented and that any related files, processes, or records are updated where necessary.

This applies to all modifications, including additions or amendments to the notes section after the initial submission has been made.

When a workflow metadata submission is received, we perform a range of validation checks to ensure that the information provided is in the correct format and is consistent with the expected requirements. However, responsibility for the accuracy of the submitted information ultimately remains with the user. Please ensure that all information provided in the submission is correct before submission wherever possible.

> **CAUTION:**
>  Making changes directly to workflow metadata files may result in inconsistencies between related records and supporting files. Always request changes through an issue so that they can be reviewed, documented, and applied correctly by the CDDS team.
