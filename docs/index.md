# CDDS CMIP7 Simulation Metadata

The Climate Data Dissemination System (CDDS) is a Python-based system that manages the reprocessing of
HadGEM3/UKCM2 and UKESM climate model data into a standards compliant ([CMOR](https://cmor.llnl.gov/))
form suitable for publication and sharing. 
CDDS has been used for CMIP6, CMIP6Plus and has now been redeveloped to support the CMIP7 data requirements.


## Contact

You can contact the CDDS team via cdds@metoffice.gov.uk.
