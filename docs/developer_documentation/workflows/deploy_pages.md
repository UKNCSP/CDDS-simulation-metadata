# [deploy_pages.yml](../../../.github/workflows/deploy_pages.yml)

## Overview

This workflow is triggered by the successful completion of [update_webview.yml](../../../.github/workflows/update_webview.yml) or via workflow dispatch. This workflow simply deploys the html created by [update_webview.yml](../../../.github/workflows/update_webview.yml) (see docs [here](../../../docs/developer_documentation/workflows/update_webview.md)) to GitHub pages.


## Connected workflows

None.
