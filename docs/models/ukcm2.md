# UKCM2-0-LL
[UKCM2-0-LL](https://egusphere.copernicus.org/preprints/2026/egusphere-2026-1676/) is a low-resolution (approx. 130km atmospheric resolution and 1° ocean resolution) coupled climate model configuration developed by the [MOHC](https://weather.metoffice.gov.uk/climate/met-office-hadley-centre) (sometimes referred to by HadGEM-GC5-Central). It is a foundational atmosphere-ocean model designed for climate sensitivity analysis. It's tuning is intended to be the base for future Earth system models like [UKESM2](https://ukesm.ac.uk/science/next-generation-model-ukesm2-0/). It has an intentionally constrained climate sensitivity of <4°C to maintain alignment with the warming range assessed by the [IPCC](https://www.ipcc.ch/).
