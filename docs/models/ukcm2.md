# UKCM2-0-LL
UKCM2-0-LL is a low-resolution (approx. 130km atmospheric resolution and 1° ocean resolution) coupled climate model configuration developed by the MOHC (sometimes referred to by HadGEM-GC5-Central). It is a foundational atmosphere-ocean model designed for climate sensitivity analysis. It's tuning intended to be the base for future Earth System Models like UKESM2. It has an intentionally constrained climate sensitivity of <4°C to maintain alignment with the warming range assessed by the IPCC.
