# UKCM2a-0-HH
UKCM2a-0-HH is a very-high resolution counterpart to [UKCM2-0-LL](https://egusphere.copernicus.org/preprints/2026/egusphere-2026-1676/) using an N640 atmosphere grid (20 km in mid latitudes, 31 km at the equator) and a 1/12 degree (8 km) extended ORCA ocean grid. UKCM2a-HH and UKCM2-0-LL share the same underlying science configuration, but UKCM2a-HH uses the COMORPH A9 atmospheric convection scheme and has various other parameter and resolution-dependent differences.
